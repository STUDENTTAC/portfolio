Campus Event Management System

Java | MySQL | Desktop Application

Project Overview

The Campus Event Management System is a software solution developed to help universities and colleges manage campus events efficiently. The system allows administrators to create events, register students, monitor attendance, and generate reports.

Problem Statement

Many institutions manage events manually using spreadsheets and paperwork. This leads to data duplication, registration errors, and difficulty tracking attendance. The Campus Event Management System automates the entire process.

Objectives

  • Automate event management processes.
  • Allow students to register for events online.
  • Track event attendance.
  • Generate reports for administrators.
  • Reduce paperwork and manual errors.

Features

  • Create and manage events.
  • Student registration.
  • Attendance tracking.
  • Event search functionality.
  • Administrative dashboard.
  • Report generation.
  • User authentication and login.

Technologies Used

  • Java
  • MySQL
  • JDBC
  • Object-Oriented Programming
  • NetBeans IDE

System Workflow

Step 1: Administrator logs into the system.


Step 2: Administrator creates an event with the event name, date, location, and description.


Step 3: Students browse available events and register.


Step 4: Attendance is recorded during the event.


Step 5: The system generates attendance and registration reports.

Database Design

The system uses a MySQL database containing the following tables:

  • Users
  • Students
  • Events
  • Registrations
  • Attendance
