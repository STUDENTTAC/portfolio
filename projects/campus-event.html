Campus Event Management System

Java | MySQL | Desktop Application

Project Overview

This system was developed to help universities manage events, student registrations, attendance tracking, and event reporting.

Problem Solved

Managing events manually is time-consuming and prone to errors. This system automates event management processes.

Features

  • Create Events
  • Student Registration
  • Attendance Tracking
  • Generate Reports
  • User Management

Technologies Used

  • Java
  • MySQL
  • JDBC
  • NetBeans

How It Works

1. Administrator logs into the system.

2. Events are created and published.

3. Students register for events.

4. Attendance is captured.

5. Reports are generated.
