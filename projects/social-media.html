Social Media Platform

PHP | MySQL | HTML | CSS | JavaScript

Project Overview

The Social Media Platform is a web application that allows users to connect, share content, communicate, and interact online. Users can create profiles, publish posts, comment on content, and engage with other users through a modern social networking environment.

Problem Statement

Many online platforms lack simple and efficient ways for users to communicate and share information. This project provides a centralized platform where users can create accounts, share updates, and build online connections.

Objectives

  • Create a secure user registration and login system.
  • Allow users to create and manage profiles.
  • Enable users to share posts and updates.
  • Provide commenting and interaction features.
  • Store and manage user data efficiently.

Key Features

  • User Registration and Login.
  • User Profile Management.
  • Create and Share Posts.
  • Comment on Posts.
  • View News Feed.
  • Manage User Accounts.
  • Database Storage for Posts and Users.

Technologies Used

  • PHP
  • MySQL
  • HTML5
  • CSS3
  • JavaScript
  • XAMPP
  • Apache Web Server

System Workflow

Step 1: User creates an account.


Step 2: User logs into the platform.


Step 3: User updates profile information.


Step 4: User creates and shares posts.


Step 5: Other users interact through comments and engagement.

Database Structure

  • Users Table
  • Profiles Table
  • Posts Table
  • Comments Table
  • Notifications Table
