SkyFlow Terminal Manager

C# | .NET | Airport Management System

Project Overview

SkyFlow Terminal Manager is an airport management system designed to improve the efficiency of airport terminal operations. The system allows airport staff to manage flights, passenger information, terminal assignments, and reporting.

Problem Statement

Airports handle large volumes of flight and passenger data daily. Traditional methods can lead to delays, scheduling conflicts, and operational inefficiencies. This project automates many of these processes.

Objectives

  • Manage flight schedules.
  • Organize terminal allocations.
  • Track passenger information.
  • Generate operational reports.
  • Improve airport efficiency.

Key Features

  • Flight scheduling and tracking.
  • Passenger management.
  • Terminal assignment management.
  • Flight status updates.
  • Search functionality.
  • Administrative dashboard.
  • Reporting system.

Technologies Used

  • C#
  • .NET Framework
  • Object-Oriented Programming
  • Visual Studio
  • SQL Database

System Workflow

Step 1: Airport staff log into the system.


Step 2: Flight information is captured.


Step 3: Terminals are assigned to flights.


Step 4: Passenger information is updated.


Step 5: Reports are generated for management.

Database Structure

  • Flights Table
  • Passengers Table
  • Terminals Table
  • Users Table
  • Reports Table
